# 🤖 Instrucciones para Copilot - Colectivos App

Este archivo contiene directrices específicas para trabajar eficientemente en el proyecto Colectivos App.

## 📋 Contexto del Proyecto

**Tipo:** Progressive Web App (PWA) de React  
**Propósito:** Consultar información de colectivos (transporte público) en La Paz, Bolivia  
**Stack:** React 19 + Tailwind CSS + React Router + Vercel  

---

## 🏗️ Arquitectura

### Capas del Proyecto

```
UI (Screens) → Components → Hooks (useColectivos) → API Endpoints
```

- **Screens:** Componentes de página que manejan la lógica de enrutamiento
- **Components:** Componentes reutilizables (ButtonPanel, ErrorMessage)
- **Hooks:** `useColectivos` centraliza fetching, loading y errores
- **Constants:** Endpoints y mapeos de colores

### Flujo de Datos

1. Usuario interactúa con un Screen
2. Screen usa `useColectivos` hook para obtener datos
3. Hook fetcha desde endpoint en `constants/endpoints.js`
4. API devuelve array de colectivos
5. Screen renderiza datos con componentes reutilizables

## 🎯 Patrones a Seguir

### 1. Componentes Funcionales con Hooks

```javascript
import { useColectivos } from '../hooks/useColectivos';

export const MiScreen = () => {
  const { colectivos, cargando, error, obtenerColectivos } = useColectivos();
  
  useEffect(() => {
    obtenerColectivos(ENDPOINTS.centro);
  }, []);
  
  return (
    <>
      {error && <ErrorMessage message={error} />}
      {cargando && <p>Cargando...</p>}
      {/* Renderizar colectivos */}
    </>
  );
};
```

### 2. Styling con Tailwind

- Usar clases Tailwind en lugar de CSS inline
- Mobile-first: empezar con estilos móviles, luego usar `md:`, `lg:` para desktop
- Los colores por línea están en `src/constants/colorsByLine.js`

Ejemplo:
```javascript
<div className="p-4 md:p-6 bg-white rounded-lg shadow-md">
  <h1 className="text-xl md:text-2xl font-bold text-gray-900">Título</h1>
</div>
```

### 3. Endpoints Centralizados

Siempre usar `ENDPOINTS` de `src/constants/endpoints.js`:

```javascript
import { ENDPOINTS } from '../constants/endpoints';

obtenerColectivos(ENDPOINTS.centro);
obtenerColectivos(ENDPOINTS.linea214);
```

No hardcodear URLs de API.

### 4. Manejo de Errores

Siempre renderizar errores con el componente `ErrorMessage`:

```javascript
{error && <ErrorMessage message={error} />}
```

### 5. Estructura de Carpetas

```
src/
├── components/
│   ├── screens/          ← Componentes de página
│   ├── reutilizables/    ← Componentes compartidos (ButtonPanel, etc)
├── hooks/                ← Custom hooks (useColectivos)
├── constants/            ← Endpoints, colores, etc
└── utils/                ← Funciones auxiliares (si se necesitan)
```

## 🔑 Puntos Clave

### Sobre PWA y Service Worker
- El Service Worker está en `public/service-worker.js`
- Detecta automáticamente nuevas versiones
- Muestra notificación flotante cuando hay actualización disponible
- **No modificar manualmente** sin entender las implicaciones

### Sobre Rutas
- La app usa `HashRouter` de React Router (por compatibilidad con Vercel)
- Las rutas están en `src/App.js`
- Nuevas rutas deben ser agregadas tanto en el router como en sus screens

### Sobre Datos
- Los datos de colectivos vienen de API externa
- Las líneas tienen códigos específicos (169, 284, 130, 0)
- Las paradas tienen IDs como `LP2060`, `LP2065`, etc
- Los datos no se persistenten (no hay BD local)

## 🐛 Debugging Tips

### Estado del Hook
```javascript
console.log({ colectivos, cargando, error });
```

### Network
- Abre DevTools → Network tab
- Verifica que los endpoints en `constants/endpoints.js` son correctos
- Comprueba CORS si hay errores

### PWA
- Abre DevTools → Application → Service Workers
- Verifica que el Service Worker está registrado
- Limpia caché si hay problemas

## 🎨 Convenciones de Código

- **Variables booleanas:** Prefijo `es`, `tiene`, `mostrar` (ej: `esVisible`, `tieneCarga`)
- **Variables de carga:** `cargando`, `cargandoColectivos`
- **Errores:** Variable `error` (string o null)
- **Callbacks:** Prefijo `manejar` (ej: `manejarClick`, `manejarEnvio`)

Ejemplo:
```javascript
const [mostrarModal, setMostrarModal] = useState(false);
const [cargando, setCargando] = useState(false);
const [error, setError] = useState(null);

const manejarAbrir = () => setMostrarModal(true);
const manejarCerrar = () => setMostrarModal(false);
```
