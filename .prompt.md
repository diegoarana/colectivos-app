# Copilot Prompt - Colectivos App

Instrucciones personalizadas para GitHub Copilot al trabajar en Colectivos App.

---

## 🎯 Contexto del Proyecto

**Colectivos App** es una Progressive Web App (PWA) desarrollada con React para consultar información de autobuses (colectivos) en La Paz, Bolivia.

- **Tech Stack:** React 19 + Tailwind CSS + React Router (HashRouter) + Vercel
- **Propósito:** Búsqueda rápida de horarios de colectivos hacia el centro y regreso
- **Tipo de usuarios:** Personas en La Paz que necesitan información de transporte

---

## 🔑 Características Que Debes Conocer

1. **PWA:** Instalable, funciona offline con Service Worker
2. **Geolocalización:** Detecta paradas cercanas al usuario
3. **Rutas dinámicas:** Parámetros como `:parada`, `:linea`, `:id`
4. **API Endpoints:** `/api/arribos` y `/api/paradas-cercanas`
5. **Deploy:** Vercel (automático en cada push)

---

## 📝 Instrucciones para Ayudar

### Cuando el usuario pide crear un nuevo Screen:

1. **Estructura base con useColectivos:**
   - Importar `useColectivos` hook
   - Importar endpoint de `ENDPOINTS` constant
   - Usar `useEffect` para obtener datos al montar
   - Renderizar con ButtonPanel o componente apropiado

2. **Manejo de estados:**
   - `{error && <ErrorMessage message={error} />}`
   - `{cargando && <p>Cargando...</p>}`
   - `{colectivos.length > 0 && <div>...</div>}`

3. **Agregar ruta:**
   - Incluir import en App.js
   - Agregar `<Route>` correspondiente
   - Mantener rutas consistentes con pattern `/ruta`

### Cuando el usuario pide agregar funcionalidad:

1. **Búscar primero:** Revisar si ya existe algo similar en otros screens
2. **Reutilizar:** Usar `ButtonPanel`, `ErrorMessage` en lugar de crear nuevos componentes
3. **Centralizar constantes:** Agregar endpoints a `endpoints.js`
4. **Manejo de errores:** Nunca renderizar texto de error sin `ErrorMessage`

### Cuando el usuario pide cambiar estilos:

1. **Tailwind first:** Usar clases Tailwind, no CSS inline
2. **Mobile-first:** Estilos base para móvil, luego `md:`, `lg:` para desktop
3. **Colores:** Usar mapeo de `colorsByLine.js` para colectivos
4. **Responsive:** Siempre verificar en mobile, tablet y desktop

### Cuando el usuario pide revisar código:

1. **Checklist:**
   - ¿Usa `useColectivos` para fetching?
   - ¿Centraliza endpoints en constants?
   - ¿Maneja error, loading y success states?
   - ¿Usa Tailwind para estilos?
   - ¿Está registrada la ruta en App.js?
   - ¿Es responsive?

## 💡 Patrones Preferidos

### ✅ Componente de Screen Ideal

```javascript
import React, { useEffect } from 'react';
import { useParams } from 'react-router-dom';
import { useColectivos } from '../../hooks/useColectivos';
import { ENDPOINTS } from '../../constants/endpoints';
import { ErrorMessage } from '../ErrorMessage';
import { ButtonPanel } from '../ButtonPanel';

export const MiScreen = () => {
  const { parametro } = useParams();
  const { colectivos, cargando, error, obtenerColectivos } = useColectivos();

  useEffect(() => {
    if (parametro) {
      const endpoint = ENDPOINTS.miEndpoint.replace('{param}', parametro);
      obtenerColectivos(endpoint);
    }
  }, [parametro]);

  return (
    <div className="min-h-screen bg-gray-50 p-4 md:p-6">
      <h1 className="text-2xl font-bold mb-6">Título</h1>
      
      {error && <ErrorMessage message={error} />}
      
      {cargando && <p className="text-center text-gray-500">Cargando...</p>}
      
      {colectivos.length > 0 ? (
        <div className="grid gap-4">
          {colectivos.map((colectivo) => (
            <ButtonPanel key={colectivo.id} {...colectivo} />
          ))}
        </div>
      ) : (
        !cargando && <p className="text-center text-gray-500">Sin resultados</p>
      )}
    </div>
  );
};
```

## 🚫 Anti-Patrones a Evitar

### ❌ No Hagas Esto

```javascript
// ❌ Hardcodear endpoints
fetch('/api/arribos?codLinea=0&idParada=LP2060')

// ❌ Estilos inline
<div style={{padding: '16px', backgroundColor: 'white'}}>

// ❌ Errores sin componente
{error && <p style={{color: 'red'}}>{error}</p>}

// ❌ useEffect sin dependencias
useEffect(() => {
  obtenerColectivos(endpoint);
}); // Corre en CADA render

// ❌ Crear componentes duplicados
// Usar ButtonPanel y ErrorMessage ya existentes

// ❌ Estilos CSS separados en App.css
// Usar Tailwind directamente en JSX
```
