# App de colectivos para ir hasta el centro y volver a casa

Progressive web app desarrollada con React y deployada con Vercel, que tiene solamente las paradas de interes para ir 
hasta el centro y volver a casa

```
Usuario abre app → SW verifica actualizaciones → Detecta nueva versión
→ Muestra notificación flotante verde → Usuario hace click en "Actualizar"
→ App se recarga con nueva versión ✅
```
